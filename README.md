# Methoden der Data Science (MODS) – WS 2026/27

Universität Paderborn

Dieses Repository enthält alle **Python-Notebooks** zur Vorlesung und Übung **Methoden der Data Science**.

## Aufbau

Jede Woche wird ein **neuer Ordner** hochgeladen. Er ist nach dem Thema der jeweiligen Vorlesung benannt und enthält die Notebooks für diese Woche.

| Ordner | Inhalt |
|---|---|
| `Intro_to_Python/` | Einführung in Python: Variablen, Funktionen, Listen, NumPy und pandas |
| `Transformation_and_Cleaning/` | Datentransformation und -bereinigung |
| `data/` | Datensätze, die in den Notebooks verwendet werden |

Weitere Ordner kommen im Laufe des Semesters dazu.

## Notebooks öffnen

Die Notebooks lassen sich direkt in **Google Colab** öffnen, ohne lokale Installation. Ersetzen Sie dafür in der GitHub-Adresse eines Notebooks `github.com` durch `colab.research.google.com/github`.

Beispiel:

```
https://colab.research.google.com/github/kbrennig/MODS_WS26_27/blob/main/Intro_to_Python/MODS_Python_Intro.ipynb
```

Die Datensätze werden in den Notebooks direkt aus dem Ordner `data/` dieses Repositorys geladen.
